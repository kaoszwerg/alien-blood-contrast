VS Code Extension · zehn Themes, ein Paket

Alien Blood Contrast

Farben direkt aus den Theme-JSON-Dateien gelesen, Scope-Auflösung wie in VS Code. Kontrastwerte nach WCAG, jeweils gegen den eigenen Hintergrund der Variante.

Kontraststufen

Beide teilen jede Hintergrundfläche — angehoben sind nur Text, Icons, Rahmen und Zeilennummern. Zeile 7 zeigt zusätzlich das Zeilen-Highlight.
